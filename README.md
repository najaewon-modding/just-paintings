# Just Paintings

플레이어가 직접 이미지를 업로드하고, 마인크래프트의 그림(Painting)처럼 월드에 전시할 수 있도록 해주는 모드입니다.

## 현재 구현 상태

- `/paintings upload <세로> <가로>` 명령어를 입력하면 OS 파일 선택 창이 열립니다.
- 선택한 이미지는 클라이언트에서 서버로 전송됩니다.
- 서버는 이미지를 PNG로 저장하고, 업로더와 그림 크기 등의 메타데이터를 함께 기록합니다.
- 저장 위치는 `<world>/njw_just_paintings/`입니다.

## 이미지 업로드

다음 명령어를 사용합니다.

`/paintings upload [세로] [가로]`

예를 들어 다음 명령어는 세로 3블록, 가로 2블록 크기의 그림에 사용할 이미지를 업로드합니다.

`/paintings upload 3 2`

명령어를 실행하면 운영체제의 파일 선택 창이 열립니다. 이미지를 선택하면 서버로 전송되며, 저장이 완료되면 성공 메시지가 출력됩니다.

## 저장 데이터

이미지 파일은 다음 위치에 저장됩니다.

`<world>/njw_just_paintings/images/`

각 이미지는 서버 내부 UUID를 파일명으로 사용하는 PNG 파일로 저장됩니다.

메타데이터는 다음 파일에 저장됩니다.

`<world>/njw_just_paintings/metadata.json`

메타데이터에는 원본 파일명, 업로더 UUID와 이름, 그림의 세로와 가로 크기, 원본 이미지의 픽셀 크기, 업로드 시각 등이 기록됩니다.

## 목표

업로드된 이미지를 마인크래프트의 그림처럼 선택하고 배치할 수 있는 사용자 지정 그림 시스템을 제공하는 것을 목표로 합니다.
