# Just Paintings

플레이어가 직접 이미지를 업로드하고, 마인크래프트의 그림(Painting)처럼 월드에 전시할 수 있도록 해주는 NeoForge 모드입니다.

## 기능

- `/paintings upload <가로> <세로>`로 이미지를 업로드합니다.
- 그림 크기는 가로·세로 각각 1~3블록입니다.
- 업로드된 이미지는 서버 월드에 저장되며 모든 플레이어가 사용할 수 있습니다.
- 사용자 지정 그림 아이템을 우클릭하면 업로드된 이미지 목록에서 하나를 선택할 수 있습니다.
- 한 번 선택한 아이템의 이미지는 변경할 수 없습니다.
- 그림 설치 시 클릭한 위치를 최초 좌상단으로 사용하며, 공간이 부족하면 필요한 만큼 위쪽 또는 왼쪽으로 보정합니다.
- 설치된 그림은 뒤쪽에 지지 블록이 하나 이상 남아 있는 동안 유지됩니다.
- `/paintings list`로 업로드된 이미지 목록을 확인하고 자신이 업로드한 이미지를 삭제할 수 있습니다.
- 삭제된 이미지를 사용하던 설치 그림은 빈 그림으로 남고, 이를 회수하면 다시 이미지를 선택할 수 있는 초기 상태의 사용자 지정 그림이 됩니다.
- 동일한 파일명을 여러 번 업로드하면 목록에서 `(2)`, `(3)`과 같이 구분합니다.
- 플레이어당 최대 10개, 서버 전체 최대 100개의 이미지를 저장할 수 있습니다.

## 이미지 업로드

다음 명령어를 사용합니다.

`/paintings upload <가로> <세로>`

예를 들어 다음 명령어는 가로 3블록, 세로 2블록 크기의 그림에 사용할 이미지를 업로드합니다.

`/paintings upload 3 2`

명령어를 실행하면 운영체제의 파일 선택 창이 열립니다. 파일 크기는 최대 16 MiB이며, 서버는 이미지를 PNG로 정규화해 저장합니다. 매우 큰 해상도의 이미지는 메모리 사용량과 렌더링 부하를 줄이기 위해 최대 2048픽셀 범위로 다운샘플링하여 저장합니다.

## 사용자 지정 그림

사용자 지정 그림은 다음 조합으로 제작합니다.

`그림 + 블레이즈 가루 → 사용자 지정 그림`

조합은 무형 조합이며, 일반 그림을 처음 획득하면 레시피가 해금됩니다.

이미지가 지정되지 않은 사용자 지정 그림을 우클릭하면 이미지 선택 화면이 열립니다. 이미지를 선택하면 파일명이 아이템 툴팁에 표시되며, 이후에는 해당 아이템의 이미지를 다시 바꿀 수 없습니다.

설치된 이미지가 서버에서 삭제된 경우 그림 자체는 즉시 사라지지 않고 빈 그림으로 표시됩니다. 이 빈 그림을 부숴 회수하면 이미지 정보가 없는 초기 상태의 사용자 지정 그림이 드롭됩니다.

## 업로드 목록

`/paintings list`

명령어를 실행하면 채팅 출력 대신 업로드된 이미지 화면이 열립니다. 이미지 선택은 할 수 없으며, 목록 확인과 본인이 업로드한 이미지 삭제만 가능합니다.

## 저장 데이터

이미지는 월드별로 다음 위치에 저장됩니다.

```text
<world>/njw_just_paintings/
├─ images/
│  └─ <uuid>.png
└─ metadata.json
```

`metadata.json`에는 이미지 UUID, 원본 파일명, 업로더 UUID와 이름, 그림의 가로·세로 크기, 원본 이미지의 픽셀 크기, 업로드 시각 등이 기록됩니다.

## 지원 버전

- Minecraft 26.1.2
- NeoForge 26.1.2.97 이상
