# Just Paintings

플레이어가 직접 이미지를 업로드하고 마인크래프트의 그림(Painting)처럼 월드에 전시할 수 있도록 해주는 NeoForge 모드입니다.

## 주요 기능

- 원하는 이미지를 서버에 업로드할 수 있습니다.
- 이미지마다 그림의 가로와 세로 크기를 블록 단위로 지정할 수 있습니다.
- 업로드된 이미지는 서버에 저장되어 여러 그림에서 사용할 수 있습니다.
- 커스텀 그림을 우클릭하면 사용 가능한 이미지 목록과 업로더를 확인할 수 있습니다.
- 원하는 이미지를 선택하여 그림에 적용할 수 있습니다.
- 지정한 크기에 맞춰 바닐라 그림처럼 벽에 배치하는 것을 목표로 합니다.

## 이미지 업로드

다음과 같은 형태의 명령어를 제공할 예정입니다.

`/upload [파일 위치] [가로] [세로]`

예를 들어 다음 명령어는 가로 2블록, 세로 3블록 크기의 그림에 사용할 이미지를 업로드합니다.

`/upload "C:\image.png" 2 3`

이미지 파일은 명령어를 실행한 플레이어의 컴퓨터에서 읽어 서버로 전송됩니다.
